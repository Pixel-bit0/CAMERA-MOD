# Web Screen (Fabric 1.20.1)

Client-side mod: shows any website on a movable, resizable screen using Chromium (MCEF).
Works on any server (it is client-only).

## Controls
- Right Shift: open the screen (rebindable)
- Right Ctrl: show/hide the pinned screen (rebindable)
- Drag the title bar to move, drag the bottom-right corner to resize
- Type a URL (or a search) in the bar, press Enter
- "Pin" keeps the screen on your HUD while you play

## Install (players)
Put in `mods/`: this jar + Fabric API + MCEF (Fabric, 1.20.1) from Modrinth/CurseForge.
